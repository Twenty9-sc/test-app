DOSSIER DES PDF DE COURS
========================

Dépose ici les fichiers PDF de tes cours. L'application les détecte
automatiquement et les affiche dans le répertoire de la bonne matière.

Fichiers attendus (fournis par l'utilisateur) :
  - Cours de C C++_copie.pdf          -> C++ (Chapitre 3)
  - cours-python_copie.pdf            -> Python (Chapitre 1)
  - notions-de-python-avancees_copie.pdf -> Python (Chapitre 5)
  - cours.pdf                         -> Python (Chapitre 6, supplément)

Pour ajouter un PDF :
  1. Copie le fichier dans ce dossier (web/pdf/).
  2. Ajoute (ou modifie) une entrée dans catalog.json avec :
        subjectId   -> matière (cpp, python, excel, arduino, anglais, espagnol)
        chapterId   -> chapitre cible
        title       -> nom affiché
        file        -> nom exact du fichier (respecte majuscules/espaces)
